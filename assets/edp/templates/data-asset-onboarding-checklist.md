# Data Asset Onboarding Checklist

## Intake
- Business owner:
- Technical owner:
- Data steward:
- Source system:
- Consumer/use case:
- Criticality tier:

## Metadata
- Business description
- Glossary terms mapped
- Schema captured
- Data classifications assigned
- Lineage documented

## Quality
- Required fields identified
- Validation rules defined
- Reconciliation checks defined
- Freshness SLA agreed
- Duplicate handling agreed

## Security & Privacy
- PII/PHI/PCI reviewed
- Access model defined
- Masking/tokenization required
- Retention policy assigned
- Audit evidence requirements captured

## Operations
- Ingestion schedule
- Monitoring/alerting
- Incident owner
- Runbook link
- Support escalation path

## Go-Live
- UAT complete
- Steward sign-off
- Control evidence attached
- Dashboard/report certified
- Post-go-live review scheduled
