# Data Governance RACI Template

| Activity | CDO/Data Office | Business Owner | Data Steward | Data Engineering | Security/Privacy | Audit |
|---|---|---|---|---|---|---|
| Define data policy | A | C | R | C | C | I |
| Approve critical data element | A | R | R | C | C | I |
| Create data quality rule | C | C | A/R | R | I | I |
| Resolve DQ exception | I | A | R | R | C | I |
| Approve access request | I | A | C | I | R | I |
| Review lineage/evidence | C | C | R | R | C | A/R |
| Sign off certified data product | A | R | R | C | C | I |

R = Responsible, A = Accountable, C = Consulted, I = Informed.
